# 权限系统 - 前端实现方案

> 本文档描述前端权限系统的架构设计和使用方式。

---

## 一、架构概览

```
┌─────────────────────────────────────────────────────────────────┐
│                        登录流程                                   │
│  loginApi() → 获取 token + userInfo + permissions               │
│            → userStore.setPermissions(permissions)              │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        权限存储                                   │
│  userStore.permissions: string[]                                │
│  例: ["device:list", "device:create", "student:list"]           │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────┬─────────────────┬─────────────────────────────┐
│   菜单权限控制    │   按钮权限控制    │      API 权限控制           │
│  authMenuList   │  v-permission   │   后端 403 返回             │
│  meta.permission│  usePermission  │   前端错误提示              │
└─────────────────┴─────────────────┴─────────────────────────────┘
```

## 三、权限码规范

### 3.1 命名格式

```
模块名:操作名
```

### 3.2 常用操作名

| 操作名   | 含义      | 说明             |
| -------- | --------- | ---------------- |
| `list`   | 列表/查询 | 通常关联菜单显示 |
| `detail` | 详情      | 查看详情页面     |
| `create` | 新增      | 新增按钮         |
| `update` | 编辑      | 编辑按钮         |
| `delete` | 删除      | 删除按钮         |
| `export` | 导出      | 导出按钮         |
| `import` | 导入      | 导入按钮         |
| `audit`  | 审核      | 审核按钮         |

### 3.3 权限码示例

| 权限码           | 含义     |
| ---------------- | -------- |
| `device:list`    | 设备列表 |
| `device:create`  | 创建设备 |
| `device:update`  | 编辑设备 |
| `device:delete`  | 删除设备 |
| `student:list`   | 学生列表 |
| `student:detail` | 学生详情 |
| `refund:audit`   | 退款审核 |

## 四、使用方式

### 4.1 按钮权限控制（v-permission 指令）

```vue
<!-- 单个权限 -->
<el-button v-permission="'device:create'">新增设备</el-button>

<!-- 多个权限（满足任一即可显示） -->
<el-button v-permission="['device:update', 'device:delete']">操作</el-button>
```

**注意**：

- 指令会直接移除无权限的 DOM 元素
- 数组模式为 **OR** 逻辑（满足任一即可）

### 4.2 代码中权限检查（usePermission Hook）

```ts
import { usePermission } from "@/hooks/usePermission";

const { hasPermission, hasAnyPermission, isSuperAdmin } = usePermission();

// 检查单个权限
if (hasPermission("device:delete")) {
  // 有删除权限
}

// 检查多个权限（全部满足）
if (hasPermission(["device:update", "device:detail"])) {
  // 同时有编辑和详情权限
}

// 检查任一权限（满足其一即可）
if (hasAnyPermission(["device:update", "device:delete"])) {
  // 有编辑或删除权限
}

// 判断是否超级管理员
if (isSuperAdmin()) {
  // 超级管理员，跳过所有权限检查
}
```

### 4.3 菜单权限配置

在 `src/config/authMenuList.ts` 中配置菜单的 `meta.permission` 字段：

```ts
{
  path: "/device/deviceControl",
  name: "deviceControl",
  component: "/device/deviceControl/index",
  meta: {
    icon: "",
    title: "公话管理",
    isLink: "",
    isHide: false,
    isFull: false,
    isAffix: false,
    isKeepAlive: false,
    permission: ["device:list"]  // 需要此权限才能看到菜单
  }
}
```

**规则**：

- `permission` 为数组，满足任一权限即可显示菜单
- 不配置 `permission` 字段，默认所有人可见
- 子菜单全部被过滤时，父菜单也会隐藏

### 4.4 复杂场景示例

```vue
<script setup lang="ts">
import { usePermission } from "@/hooks/usePermission";

const { hasPermission } = usePermission();

// 编辑按钮：需要权限 + 业务状态判断
const showEditButton = (row: any) => {
  if (!hasPermission("device:update")) return false;
  if (row.status === "locked") return false;
  return true;
};

// 删除按钮：需要权限 + 不能删除已绑定设备
const showDeleteButton = (row: any) => {
  if (!hasPermission("device:delete")) return false;
  if (row.bindCount > 0) return false;
  return true;
};
</script>

<template>
  <el-table-column label="操作">
    <template #default="{ row }">
      <el-button v-if="showEditButton(row)" @click="handleEdit(row)"> 编辑 </el-button>
      <el-button v-if="showDeleteButton(row)" @click="handleDelete(row)"> 删除 </el-button>
    </template>
  </el-table-column>
</template>
```

## 五、后端接口要求

### 5.1 登录接口

**接口**：`POST /admin/auth/login`

**响应**：

```json
{
  "code": 0,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "userInfo": {
      "id": 123,
      "username": "zhangsan",
      "realName": "张三",
      "roleCode": "agent_admin",
      "tenantId": 2
    },
    "permissions": ["device:list", "device:create", "device:update", "student:list", "student:detail"]
  }
}
```

### 5.2 403 错误响应

当用户越权操作时，后端返回：

```json
{
  "code": 403,
  "msg": "您没有权限执行此操作"
}
```

前端会自动显示错误提示。

## 六、特殊角色处理

### 6.1 超级管理员

`role_key === "super_admin"` 时：

- 跳过所有权限检查
- 显示所有菜单
- 所有按钮可见

### 6.2 代理商管理员

`role_key === "agent_admin"` 时：

- 按权限码列表进行权限控制
- 数据范围由后端自动过滤

## 七、开发流程

### 7.1 新增功能模块

1. **与后端确认权限码**

   ```
   模块: 订单管理
   权限码: order:list, order:detail, order:create, order:update, order:delete, order:export
   ```

2. **配置菜单权限**（`authMenuList.ts`）

   ```ts
   {
     path: "/order",
     name: "order",
     meta: {
       title: "订单管理",
       permission: ["order:list"]
     },
     children: [
       {
         path: "/order/list",
         name: "orderList",
         meta: {
           title: "订单列表",
           permission: ["order:list"]
         }
       }
     ]
   }
   ```

3. **页面按钮权限**

   ```vue
   <el-button v-permission="'order:create'">新增订单</el-button>
   <el-button v-permission="'order:export'">导出</el-button>
   ```

4. **操作列权限**
   ```vue
   <el-button v-permission="'order:detail'" link>查看</el-button>
   <el-button v-permission="'order:update'" link>编辑</el-button>
   <el-button v-permission="'order:delete'" link type="danger">删除</el-button>
   ```

## 九、注意事项

1. **前端权限仅为 UX 优化**：真正的权限控制在后端，前端隐藏按钮只是提升用户体验
2. **权限修改后需刷新**：权限列表在登录时获取，修改后需重新登录或刷新页面
3. **避免过度使用**：简单的显示/隐藏用 `v-permission`，复杂业务逻辑用 `usePermission`
4. **保持权限码一致**：前后端使用相同的权限码命名
