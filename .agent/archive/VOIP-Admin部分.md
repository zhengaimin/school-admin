# VOIP Admin 部分

## 一期目标

管理后台沿用现有设备组和设备管理入口，由后端在业务操作中同步维护微信设备组。Admin 不直接调用微信接口，只负责提交业务操作、约束高风险操作并清晰展示同步结果。

## 一期任务

### 设备组管理

- 创建设备组时继续提交 `name`、`code`、`isVoipGroup` 等业务字段。
- VOIP 设备组由后端同步创建微信 group；Admin 不展示或编辑 `wechat_group_id`。
- 编辑设备组时禁用 `name`、`code`、`isVoipGroup`，只允许修改后端允许的普通字段。
- 设备组导入前提示微信同步耗时和风控风险；失败时展示 Excel 行号、设备组名称和失败原因，允许重新上传。
- 微信同步失败时展示后端原始业务提示，不做前端隐式重试。

### 设备管理

- 创建设备时可以选择设备组；编辑设备基础信息时禁止变更设备组。
- 设备换校或换组统一使用 `POST /admin/devices/:id/change-school`。
- 换入 VOIP 设备组前二次确认，提示操作会同步微信设备组。
- 删除已分组设备前二次确认；后端完成微信 group 移出后才删除本地设备。
- 设备导入前二次确认；导入完成后展示成功数、失败数和逐条失败原因，支持修正后重试。
- 批量绑组单次最多选择 20 台设备；目标为 VOIP 设备组时二次确认。
- 批量绑组展示 `total`、`success` 和 `{sn, reason}` 失败明细，失败设备可重新选择后重试。

## 接口

| 场景       | 接口                                     |
| ---------- | ---------------------------------------- |
| 设备组创建 | `POST /admin/device-groups`              |
| 设备组更新 | `PUT /admin/device-groups/:id`           |
| 设备组导入 | `POST /admin/device-groups/import-excel` |
| 设备创建   | `POST /admin/devices`                    |
| 设备导入   | `POST /admin/devices/import`             |
| 换校或换组 | `POST /admin/devices/:id/change-school`  |
| 批量绑组   | `POST /admin/devices/batch-assign-group` |
| 删除设备   | `DELETE /admin/devices/:id`              |

## 页面边界

- 不展示 `wechat_group_id`、`groupId`、`model_id`、`snTicket`。
- 不在前端判断是否真正完成微信同步，以接口成功结果为准。
- 不绕过后端 20 台硬限制；前端也应在提交前拦截。
- 不在一期开发订阅统计、同步监控、孤儿订阅排查和对账任务。

## 验收

- 编辑设备组时 `name`、`code`、`isVoipGroup` 不可修改。
- VOIP 导入、换组、批量绑组等高风险操作均有二次确认。
- 后端返回同步错误时，页面能展示具体原因并保留重试路径。
- 批量绑组超过 20 台时不发起请求；部分失败时能查看每台设备的失败原因。
- 普通设备组操作仍可沿用原流程，不出现微信技术字段。

## 待确认

- 产品需最终确认设备组名称创建后不可修改；一期当前按不可修改实现。
- 产品需确认“SN 不存在、未激活、不可加入组”等错误是否需要分别配置运营话术；未确认前展示后端原因。
