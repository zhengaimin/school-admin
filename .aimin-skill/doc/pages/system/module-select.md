# system/module-select 页面规格

## 页面目标

- 提供登录后模块入口选择，并按账号权限显示可进入模块。

## 页面主要逻辑

1. 页面展示模块卡片列表，点击后进入目标模块首个可见菜单。
2. 普通账号根据权限模块接口结果过滤可见模块。
3. 超级管理员账号仅展示权限模块（`system`）。

## 关键接口

| 接口                         | 方法 | 用途                       | 备注                 |
| ---------------------------- | ---- | -------------------------- | -------------------- |
| `/admin/permissions/modules` | GET  | 获取当前用户可访问权限模块 | 普通账号用于模块过滤 |

## 注意点

1. 超级管理员判断统一使用 `roleLevel === super` 的工具方法，不再使用 `roleCode`。
2. 超级管理员在本页面的模块可见范围固定为 `system`。
