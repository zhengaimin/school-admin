# context 使用说明

本目录用于存放项目开发规范与模板，供 Codex/AI 与开发者在实现功能时参考与遵循。

## 目录说明

- `api.md`：接口与类型规范
- `constant.md`：常量与枚举规范
- `constant-index.md`：枚举索引（维护表）
- `naming.md`：通用命名规范
- `admin/table-page.md`：表格 + 弹窗页面规范
- `admin/vue.md`：Vue 开发规范与约定

## 使用约定

- 新增/修改枚举后，必须同步更新 `constant-index.md`。
- 若新增新的规范文档，请在本说明中补充。
- 开发前先阅读相关规范，避免重复返工。

## 通用

- 变量/方法/计算属性必须添加中文 /\*\* \*/ 注释。

## 推荐流程

1. 阅读对应规范（接口/枚举/页面）。
2. 按规范实现代码并补充索引。
3. 若规范有变更，及时同步文档。
